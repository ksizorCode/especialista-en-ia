Ejemplos cortos, progresivos y listos para copiar. Empieza creando arrays y termina filtrando, transformando y analizando datos.

01 · Arrays

Crear y rellenar

La base: datos en una o varias dimensiones.

CódigoResultadoQué hace
import numpy as np—Importa NumPy.
np.array([1, 2, 3])[1 2 3]Crea un array 1D.
np.array([[1, 2], [3, 4]])[[1 2]\n [3 4]]Crea una matriz 2D.
np.zeros((2, 3))[[0. 0. 0.]\n [0. 0. 0.]]Rellena con ceros.
np.ones((2, 3))[[1. 1. 1.]\n [1. 1. 1.]]Rellena con unos.
np.full((2, 2), 7)[[7 7]\n [7 7]]Rellena con un valor.
np.eye(3)[[1. 0. 0.]\n [0. 1. 0.]\n [0. 0. 1.]]Crea identidad.

import numpy as np

ventas = np.array([12, 8, 15, 10])
matriz = np.zeros((2, 3))

print(ventas)
print(semanas)

02 · Consultar

Mirar, indexar y cortar

Accede justo a los datos que necesitas.

CódigoResultadoQué hace
a[0]10Accede por índice.
a[-1]40Accede desde el final.
a[1:4][20 30 40]Corta un rango.
m[0, 1]2Accede a una celda.
m[:, 0][1 4]Selecciona una columna.
a.shape · a.ndim(4,)Consulta forma y ejes.
a.size · a.dtype4Consulta tamaño y tipo.
Ejemplo práctico · copia y ejecuta
a = np.array([10, 20, 30, 40])
m = np.array([[1, 2, 3], [4, 5, 6]])

print(a[0], a[-1])      # 10 40
print(a[1:3])           # [20 30]
print(m[:, 1])           # [2 5]
print(m.shape, m.size)  # (2, 3) 6
03 · Operar

Calcular y resumir

Operaciones rápidas sobre todos los elementos.

CódigoResultadoQué hace
a + b · a * b[11 22 33]Suma o multiplica arrays.
a * 10 · a ** 2[100 200 300]Opera con un escalar.
a.sum() · a.mean()45 · 11.25Resume los datos.
a.max() · a.min()15 · 8Encuentra extremos.
a.std()2.59…Mide dispersión.
m.sum(axis=0) · m.sum(axis=1)[5 7 9] · [ 6 15]Resume por eje.

Ejemplo práctico · copia y ejecuta
precios = np.array([10, 12, 8, 15])

print(precios * 1.21)   # IVA
print(precios.sum())    # total: 45
print(precios.mean())   # media: 11.25
print(precios.max())    # máximo: 15
print(precios.argmax()) # posición: 3
04 · Filtrar

Condiciones y búsqueda

Quédate con los datos que cumplen una regla.

CódigoResultadoQué hace
a > 5[False True True]Comprueba una condición.
a[a > 5][ 7 9 10]Filtra valores.
np.where(a > 5, 1, 0)[0 1 1]Convierte una condición.
np.nonzero(a)(array([1, 2]),)Busca posiciones.
np.unique(a)[1 2 3]Elimina duplicados.
Ejemplo práctico · copia y ejecuta
notas = np.array([4, 7, 9, 5, 10])
aprobados = notas[notas >= 5]
etiquetas = np.where(notas >= 5, "aprobado", "suspenso")

print(aprobados) # [ 7  9  5 10]
print(etiquetas)
