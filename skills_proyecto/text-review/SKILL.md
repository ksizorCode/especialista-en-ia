# Text review

Use this skill when reviewing notebook explanations, interface copy, labels, errors, documentation, or project text.

- Preserve the intended meaning while correcting spelling, grammar, punctuation, accents, terminology, and inconsistent capitalization.
- Match the project's language and audience; use concise, concrete wording for labels and actionable wording for errors.
- Keep technical names, metric names, units, and model outputs precise and consistent.
- Avoid unexplained jargon, ambiguous claims, unnecessary passive voice, and promises stronger than the evidence.
- Check headings, button labels, placeholders, alt text, and validation messages as one coherent experience.
- Report substantive wording changes when the user asks for review rather than a rewrite.
