# Dataset creation

Use this skill when a project needs a dataset before exploration or model training.

- Clarify the prediction target, input features, task type, expected schema, and licensing or provenance requirements.
- Prefer authoritative, reproducible sources and record the source, version/date, download method, and transformations.
- Validate columns, data types, missing values, duplicates, outliers, class balance, and possible target leakage.
- Keep raw data separate from processed data; make transformations reproducible with a script or notebook.
- Do not invent data or silently discard rows. Explain and document any filtering, imputation, encoding, or sampling.
- Produce a concise data dictionary and a machine-readable file when appropriate (CSV, Parquet, or equivalent).
