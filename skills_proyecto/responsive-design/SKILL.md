# Responsive design

Use this skill for the visual and interaction behavior of the prediction page at different viewport sizes.

- Start from the smallest practical viewport and progressively enhance for larger screens.
- Prefer flexible layout primitives such as CSS Grid, Flexbox, intrinsic sizing, and fluid spacing over fixed coordinates.
- Define breakpoints from content needs, not device names; verify form, result, navigation, and error states at each relevant width.
- Keep touch targets, readable text, focus indicators, contrast, and keyboard navigation accessible.
- Prevent horizontal overflow, clipped labels, and layout shifts caused by loading or validation messages.
- Test representative narrow, medium, and wide viewports before delivery.
