# Data exploration

Use this skill to create or improve an `.ipynb` exploratory analysis.

- Use pandas for loading, inspection, cleaning checks, summaries, grouping, and feature analysis; use matplotlib for plots.
- Organize the notebook into purpose, data loading, quality checks, univariate analysis, relationships, target analysis, and conclusions.
- Add Markdown explanations before significant code and state what each result means for modeling.
- Include clear labels, units, legends, readable scales, and reproducible random seeds where sampling is used.
- For classification, include class distribution and, when predictions are available, a confusion matrix with labeled axes.
- Avoid hiding errors with blanket exception handling or presenting correlation as causation.
- Execute the notebook before delivery and ensure outputs match the current data and code.
