# Layout and positioning

Use this skill when arranging page sections, forms, cards, controls, or prediction results.

- Establish a clear container, spacing scale, alignment model, and stacking context before adjusting individual elements.
- Prefer normal flow, Grid, Flexbox, margins, padding, and `gap`; reserve absolute or fixed positioning for overlays and intentional viewport UI.
- Keep elements anchored to meaningful parents and ensure content can grow without overlap.
- Check z-index, overflow, focus order, and resizing behavior whenever positioning is changed.
- Use semantic HTML and logical alignment so the layout remains understandable and accessible.
- Verify the result with long labels, validation messages, different font sizes, and small screens.
