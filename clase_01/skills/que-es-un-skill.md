# SKILLS

¿Qué es un Skill?
La truaducción literal sería una 'habilidad', pero a afectos prácticos es un texto con instrucciones que funciona como prompt retuilizable con las características a repetir a modo de pautas para realizar una tarea determinada

¿Cómo instalarlo o configurarlo?

En la carpeta del proyecto:

```
.agents
- skills
- nombre del skill
- SKILL.md
```

Formato del archivo skill.md

````
---
name:
description:
---
