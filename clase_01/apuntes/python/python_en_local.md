# Instala Python en Local:

- Instalamos Python en local a través de la web: https://www.python.org/
Se abrirá una terminal y pulsaremos Y y luego ENTER cada vez que nos pregunte.

- Abrimos VSCode
- Control + Shift + N para crear nueva ventana.
- Arrastramos en esta nueva ventana una carpeta con el nombre del proyecto.
- Creamos un archivo llamado 'hola.py'
- La primera vez el proppio VSCode nos sugerirá descargar la extensión de ayuda para trabajar con Python. Aceptamos.


- Ya podemos empezar a programar:

```python

print('Hola Mundo')

```
