# Atajos de teclado

## Qué son y para qué sirven

Un atajo de teclado es una combinación de teclas que ejecuta una acción sin tener que buscarla con el ratón. Permite trabajar más rápido, reduce movimientos repetitivos y resulta especialmente útil al programar, editar documentos o navegar.

La tecla `Ctrl` de Windows suele equivaler a `Cmd (⌘)` en macOS. En este documento se muestran principalmente atajos de Windows; en macOS puede sustituirse `Ctrl` por `Cmd` cuando se indique.

## Ejemplos prácticos

### Ejemplo 1: editar un archivo en VS Code

1. Pulsa `Ctrl + P` y escribe el nombre del archivo.
2. Pulsa `Ctrl + F` para localizar el texto.
3. Pulsa `F2` sobre una función para renombrarla correctamente en todo el proyecto.
4. Pulsa `Shift + Alt + F` para formatear el documento.
5. Pulsa `Ctrl + S` para guardar.

### Ejemplo 2: investigar un error en el navegador

1. Pulsa `Ctrl + Shift + I` para abrir las herramientas de desarrollador.
2. Entra en la pestaña **Console** para leer errores.
3. Pulsa `Ctrl + R` para reproducir la carga.
4. Usa `Ctrl + F` para localizar un mensaje.
5. Pulsa `Ctrl + Shift + R` si necesitas ignorar la caché.

## Cómo personalizar atajos en VS Code

Abre la paleta con `Ctrl + Shift + P`, busca **Preferences: Open Keyboard Shortcuts** y selecciona la acción que quieras cambiar. También puedes abrir el archivo JSON de atajos y añadir una regla:

```json
{
	"key": "ctrl+alt+t",
	"command": "workbench.action.terminal.new"
}
```

Los atajos pueden variar según el sistema operativo, la distribución del teclado, el navegador y las extensiones instaladas. Para consultar todos los atajos de VS Code, usa `Ctrl + K` y después `Ctrl + S`.
