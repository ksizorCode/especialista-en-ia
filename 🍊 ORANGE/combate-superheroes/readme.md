# Prediccion de quien ganería en un combate

1. Le pasamos un Dataset de combates con una serie de características para el jugador A y el jugador B
2. En el archivo heroes.csv se listan todas las características individuales de cada luchador (este archivo es meramente informativo para nosotros)

3. Plantilla-combate.csv aquí ponemos restamos las características entre los 2 luchadores que se van a enfrentar. (Si lucha Spiderman -A vs Green Arrow - B  y spiderman tiene una puntuación de 8 en velocidad y Green Arrow de 4, en la plantilla pondremos 4 como diferencia entre ellos en la columan diferencia_velocidad)
